Fork of [SmartLoot](https://github.com/Necroskillz/SmartLoot) by Necroskillz.

Replaces the default group loot roll frames with a compact stack you can drag
anywhere, and remembers per-item roll rules so you stop clicking greed on the
same junk every run. `/sloot` for options.

Changes from the original:

- ported to 3.3.5a, won't load on 1.12 any more
- disenchant rolls, as a button and as an autoroll rule
- settings saved per character
